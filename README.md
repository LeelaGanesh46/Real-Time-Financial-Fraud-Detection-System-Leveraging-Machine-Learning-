# Real-Time Financial Fraud Detection System

## 🚀 Project Overview
This project implements a **financial fraud detection system** that uses machine learning to classify transactions as *fraudulent* or *legitimate*. The goal is to help analysts identify suspicious financial behavior automatically and accurately.

---

## ✅ Objective
- Detect fraudulent financial transactions using statistical and ML techniques.  
- Analyze the dataset to find patterns and anomalies.  
- Train a model that predicts fraud effectively.

---

## 🛠️ Tools & Technologies
- **Python**
- **Jupyter Notebook**
- **Pandas**, **NumPy**
- **Scikit-Learn**
- **Machine Learning Classification Models**
- **Model Serialization (.pkl)**

---

## 📁 Repository Contents
| File | Description |
|------|-------------|
| `fraud_detection_training_model.ipynb` | Notebook for data analysis, preprocessing & model training |
| `model.pkl` | Trained machine learning model stored |
| `model_features.pkl` | Model feature list |
| `app.py` | Script for running predictions |
| `data.csv` | Dataset used for training |

---

## 🧠 Steps Performed
1. **Data Exploration & Cleaning**  
   - Loaded dataset  
   - Checked for missing/null values  
   - Handled class imbalance  

2. **Feature Engineering**  
   - Selected important features  
   - Scaled/normalized values if needed

3. **Model Training & Evaluation**  
   - Built classification models  
   - Evaluated using accuracy, precision, recall

4. **Model Export**  
   - Saved trained model in `.pkl` format for reuse
