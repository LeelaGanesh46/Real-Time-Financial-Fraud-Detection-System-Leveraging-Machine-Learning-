# Real-Time Financial Fraud Detection System

## 🚀 Project Overview
This project implements a **financial fraud detection system** that uses machine learning to classify transactions as *fraudulent* or *legitimate*. The goal is to help analysts identify suspicious financial behavior automatically and accurately.

---

## ✅ Objective
- Detect fraudulent financial transactions using statistical and ML techniques.  
- Analyze the dataset to find patterns and anomalies.  
- Train a model that predicts fraud effectively.

---

## 🛠️ Tools & Technologies
- **Python**
- **Jupyter Notebook**
- **Pandas**, **NumPy**
- **Scikit-Learn**
- **Machine Learning Classification Models**
- **Model Serialization (.pkl)**
